# Online Retail Sales Analysis

## Project Overview
This project focuses on analyzing online retail sales data using MySQL and Microsoft Excel. The project was developed to identify sales trends, top customers, product performance, and revenue insights through SQL queries, Pivot Tables, and interactive dashboards.

---

## Technologies Used
- MySQL Workbench
- SQL
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Visualization

---

## Features
- Total Revenue Analysis
- Product-wise Revenue Analysis
- Gender-wise Sales Analysis
- Monthly Sales Trend Analysis
- Top Customers Analysis
- Interactive Excel Dashboard
- SQL Query Execution and Output Analysis

---

## SQL Concepts Used
- SELECT Statements
- Aggregate Functions (`SUM`, `AVG`)
- `GROUP BY`
- `ORDER BY`
- Data Filtering
- Revenue Calculations

---

## Dashboard Components
The Excel dashboard includes:
- Revenue by Product Category
- Monthly Revenue Trend
- Gender-wise Revenue Analysis
- Top Performing Customers
- Pivot Tables and Charts

---

## Project Workflow
1. Created retail sales database in MySQL Workbench.
2. Inserted and managed sales data using SQL.
3. Executed SQL queries to analyze sales performance.
4. Exported analyzed data to Microsoft Excel.
5. Built Pivot Tables, Charts, and Dashboard visualizations.
6. Uploaded project files and screenshots to GitHub.
