# Online Retail Sales Analysis

## Project Overview
This project focuses on analyzing online retail sales data using SQL and Excel to identify business trends, customer behavior, and sales performance.

## Technologies Used
- MySQL
- MS Excel

## Features
- Developed an interactive retail sales dashboard using Excel Pivot Tables and charts.
- Performed sales trend, customer, and category analysis using SQL queries.
- Generated business insights on monthly revenue, top customers, and gender-wise sales.

## Files Included
- `retail_sales.sql` – SQL queries and database analysis
- `Online_Retail_Sales_Analysis.xlsx` – Dataset and dashboard

## Key Insights
- Identified monthly revenue trends
- Analyzed top-performing customers
- Compared gender-wise sales performance
- Evaluated category-wise sales distribution

## Conclusion
This project demonstrates the use of SQL and Excel for retail business analytics and data-driven decision-making.
